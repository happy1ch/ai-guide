1. 개념

터미널은 컴퓨터에게 글로 주문하는 창

마우스로 쓰는 화면은 메뉴판을 보고 손가락으로 고르는 식당입니다. 터미널은 주방에 "김치찌개 2인분"처럼 정확히 적어 주문하는 방식입니다. 배우는 데 시간이 걸리지만, 같은 주문을 정확히 반복하고 AI에게 대신 시킬 수 있습니다.

그래픽 화면 (보통 쓰는 방식)

버튼과 아이콘을 눈으로 보고 클릭합니다. 직관적이지만 여러 단계를 사람이 직접 눌러야 합니다.

터미널 (글자로 명령)

명령을 쓰고 Enter를 누르면 결과가 글자로 나옵니다. AI 도구가 컴퓨터를 다룰 때도 이 방식을 씁니다.

2. 설치의 원리

왜 .exe를 누르지 않고 터미널로 설치할까

사실 파이썬도 홈페이지에서 .exe를 받아 눌러 설치할 수 있습니다. 그런데 개발 도구는 터미널로 설치하는 방법이 표준입니다. 이유는 패키지 관리자라는 배달원이 있기 때문입니다.

.exe 방식: 내가 장 보러 가기

사이트를 찾고, 맞는 버전을 고르고, 파일을 받고, "다음"을 여러 번 누릅니다. 가짜 사이트를 받을 위험도 있고, 업데이트도 내가 직접 해야 합니다.

터미널 방식: 배달 앱으로 주문

이름만 말하면 공식 목록에서 찾아 받아 설치하고, 길 안내(PATH)까지 등록합니다. 한 줄이라 그대로 복사해 두면 다른 컴퓨터에서도 똑같이 됩니다.

패키지 관리자는 설치하는 대상에 따라 이름이 다릅니다.

패키지 관리자무엇을 설치하나명령 예
wingetWindows 프로그램 (VS Code, Git, Python 본체 등). Windows 11에 기본으로 들어 있습니다.winget install -e --id Git.Git
pip파이썬용 부품(라이브러리). 파이썬 안에서 쓰는 도구 모음입니다.pip install requests
npmNode.js용 부품과 도구. 일부 AI 도구도 이 방식으로 설치합니다.npm install -g 패키지이름

AI 도구로 컴퓨터를 다룰 계획이라면 아래 순서로 갖춰 두면 대부분 풀립니다. 이미 있는 것은 건너뛰세요.

프로그램하는 일설치 명령 (winget)
터미널기본 제공Windows 11에 PowerShell과 Windows Terminal이 이미 있습니다. 따로 설치할 필요가 없습니다.시작 메뉴에서 "터미널" 검색

6. 파이썬과 JSON 체험

파이썬은 "글로 쓴 작업 지시서"

파이썬 파일(.py)은 컴퓨터가 위에서 아래로 읽는 지시서입니다. 메모장으로 만든 파일을 python 파일이름.py로 실행하면 그대로 따릅니다.

# hello.py 파일 내용 name = "홍길동" print("안녕하세요,", name, "님") print(1 + 2)
PS> python hello.py 안녕하세요, 홍길동 님 3
첫 줄은 이름표(변수)를 붙이는 것, print는 화면에 보여 주는 것입니다.

JSON: 정보를 정리해 담는 약속된 서식

JSON은 설정과 데이터를 "이름: 값" 짝으로 적는 글자 형식입니다. AI 도구의 설정 파일 대부분이 JSON입니다. 아래 칸에서 직접 고쳐 보세요. 쉼표나 따옴표를 하나 지우면 오류가 나는 것도 확인해 보세요.

컴퓨터가 읽은 결과

규칙은 네 가지입니다. ① 전체를 { }로 감싼다 ② 이름은 큰따옴표 ③ 항목 사이는 쉼표(마지막 뒤에는 없음) ④ 값은 글자, 숫자, true/false, 목록 [ ], 묶음 { } 중 하나.

6-2. 자주 헷갈리는 한 쌍

.env와 venv, 이름은 비슷하지만 하는 일이 다릅니다

둘은 서로 관계가 없습니다. 다만 한 프로젝트 폴더에 같이 들어 있는 경우가 많아서 같은 것으로 착각하기 쉽습니다.

.env: 비밀 메모지를 넣는 금고

API 키, 비밀번호, 주소처럼 코드에 직접 쓰면 안 되는 값을 따로 적어 둔 글자 파일입니다. 코드를 남에게 보내도 키는 같이 나가지 않습니다.

venv: 프로젝트마다 따로 쓰는 공구함

프로젝트가 쓰는 파이썬 부품을 폴더 하나에 따로 모아 둡니다. A는 부품 1.0, B는 2.0이 필요해도 서로 부딪치지 않습니다.

.envvenv (가상환경)
정체글자 파일 하나폴더 하나 (파이썬 본체 복사본과 부품이 들어 있음)
담는 것비밀 값과 설정 (API 키, 비밀번호, 주소)이 프로젝트용 파이썬 부품과 그 버전
풀어 주는 문제비밀 키를 코드에 쓰면 유출됨프로젝트마다 필요한 부품 버전이 달라 충돌함
만드는 법메모장으로 이름=값을 적음python -m venv .venv
쓰는 법프로그램이 시작할 때 읽어 감터미널에서 "켜기" 명령을 한 번 실행
Git에 올리나올리지 않음 (비밀이라서)올리지 않음 (크고 다시 만들 수 있어서)

실제로는 이렇게 같이 보입니다

# .env 파일 내용 (이름=값, 따옴표 없이) ANTHROPIC_API_KEY=여기에-비밀-키 CHURCH_NAME=예시교회
실제 키를 넣은 .env 내용은 AI 채팅창에 붙여 넣지 마세요.
PS> python -m venv .venv PS> .venv\Scripts\Activate.ps1 # 줄 맨 앞에 (.venv)가 보이면 공구함이 켜진 상태 (.venv) PS> pip install python-dotenv
.venv는 이 폴더 안에 공구함을 만드는 명령입니다. 켠 뒤에 설치한 부품은 이 프로젝트에만 들어갑니다.
# main.py 안에서 .env 읽기 from dotenv import load_dotenv import os load_dotenv() key = os.getenv("ANTHROPIC_API_KEY")
여기서 두 가지가 만납니다. .env를 읽는 부품(python-dotenv)을 venv 안에 설치한 것입니다.

주의

  • .env에는 요금이 나가는 열쇠가 들어 있을 수 있습니다. 남에게 보내거나 GitHub에 올리지 마세요.
  • 에러 메시지를 AI에게 물어볼 때 키가 섞여 있으면 그 부분을 지우고 붙여 넣으세요.
  • venv는 폴더째 다른 곳으로 복사해서 옮기지 마세요. 새 곳에서 python -m venv .venv로 다시 만들고 부품을 다시 설치하는 편이 안전합니다.

빨간 글자가 떠도 당황하지 마세요

에러 읽는 요령

가장 아래 줄에 핵심 원인이 있는 경우가 많습니다. 위쪽 긴 글은 "어디서 났는지" 기록일 뿐입니다. 전체를 복사해서 AI에게 "이 에러가 무슨 뜻이고 어떻게 고치지?"라고 물으면 대부분 해결됩니다.

자주 만나는 메시지

not recognized: 설치가 안 됐거나 터미널을 다시 켜야 합니다.
Permission denied: 권한 문제. 관리자 권한 터미널이 필요할 수 있습니다.
No such file: 파일 이름이나 현재 폴더가 틀렸습니다.

프로그램 이름, 설치 ID, 메뉴 표기는 버전에 따라 달라질 수 있습니다. 설치 명령이 실패하면 오류 메시지를 AI에게 보여 주거나 각 프로그램 공식 사이트의 안내를 확인하세요. 모르는 명령은 실행 전에 의미부터 물어보세요.
