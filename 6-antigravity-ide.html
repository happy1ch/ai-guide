번호를 눌러 보세요

2. 구역 나누기

화면은 크게 네 구역입니다

VS Code를 써 보셨다면 거의 같은 모양입니다. 달라지는 곳은 오른쪽의 에이전트 패널입니다.

3. 에이전트 패널

AI에게 일을 시키는 곳

화면 오른쪽의 "Agent" 창입니다. 채팅창처럼 보이지만, 내 폴더의 파일을 읽고 고치며 터미널 명령까지 실행하는 에이전트와 대화하는 곳입니다.

대화와 사진 첨부

이 화면의 첫 메시지처럼 캡처한 사진을 붙여 질문할 수 있습니다. 오류가 나면 화면을 캡처해 보여 주세요.

"Thinking" 표시

에이전트가 생각 중이라는 뜻입니다. 답이 나오기 전까지 기다리면 되고, 엉뚱한 방향이면 빨간 정지 버튼을 누릅니다.

입력창의 @와 /

@를 치면 파일이나 폴더를 콕 집어 지정하고, /를 치면 동작 목록이 나옵니다.

모델 선택

입력창 왼쪽 아래에 Claude Sonnet 4.6 (Thinking)이 보입니다. 구글이 만든 도구 안에서 Anthropic의 Claude를 고른 모습입니다. 눌러서 다른 모델로 바꿀 수 있습니다.

이 화면이 보여 주는 것

  • Antigravity는 한 회사의 AI에 묶여 있지 않고, 모델 선택 메뉴에서 여러 회사의 모델을 고를 수 있습니다.
  • (Thinking)이 붙은 모델은 답하기 전에 더 오래 생각하는 방식입니다. 어려운 일에 쓰고, 간단한 일에는 빠른 모델을 쓰면 한도를 아낄 수 있습니다.

처음 일을 시킬 때의 순서

  1. 작업할 폴더를 엽니다File 메뉴에서 폴더 열기를 고릅니다. AI가 만지는 범위가 이 폴더 안으로 정해집니다.
  2. 입력창에 하고 싶은 일을 씁니다처음에는 "계획서부터 써 줘"처럼 실행 전에 계획만 받는 요청이 안전합니다.
  3. 계획서와 승인 요청을 읽습니다터미널 명령을 실행하기 전에 승인을 묻도록 설정해 두었다면, 내용을 읽고 허락합니다.
  4. 무엇이 바뀌었는지 확인합니다편집기에서 바뀐 파일을 열어 보고, 소스 제어 아이콘의 숫자(변경된 파일 수)로도 확인합니다.
4. 확장 프로그램

이 화면의 왼쪽은 확장 프로그램 목록입니다. 확장 프로그램은 편집기에 기능을 덧붙이는 부품입니다. 그림에는 두 가지가 눈에 띕니다.

6. 주의

쓰기 전에 알아 둘 점

안전 수칙

  • 확장 프로그램은 내 컴퓨터의 권한으로 동작합니다. 모르는 게시자의 확장은 설치하지 마세요. 설치 전에 게시자와 설치 수를 확인하세요.
  • 터미널 명령 실행을 "자동"으로 두면 삭제 명령도 실행될 수 있습니다. 처음에는 "매번 검토 요청"으로 두세요.
  • 화면을 캡처해 AI나 다른 사람에게 보낼 때는 폴더 경로, 계정 사진, 키와 비밀번호가 찍혀 있지 않은지 먼저 확인하세요.
  • 중요한 폴더는 작업 전에 다른 곳에 복사해 두세요.
화면 구성과 메뉴 이름은 Antigravity 버전에 따라 달라질 수 있습니다. 번호 설명 중 일부(상태 표시줄의 작업 영역 이름, 확장이 표시하는 항목)는 화면 모양으로 추정한 것이라 실제 이름과 다를 수 있습니다.
