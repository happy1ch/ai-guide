요즘 나온 AI 도구 네 가지

Hermes Agent, Jev, Aside Browser, Muse. 이름은 비슷하게 들려도 하는 일이 모두 다릅니다. 직원에 비유해서 무엇을 잘하는지 쉽게 풀었습니다.

1. 한눈에

한 줄로 말하면

앞 페이지의 Claude Code, Codex, Antigravity는 "내 폴더에서 일하는 작업실"이었습니다. 이번 네 가지는 모양이 서로 다릅니다.

Hermes Agent

메신저에 사는 24시간 비서

내 컴퓨터나 서버에서 계속 돌며 텔레그램 같은 메신저로 대화하고, 기억하고, 정해진 시간에 일합니다.

2. Hermes Agent

내 메신저에 사는 24시간 비서

Nous Research오픈소스

Claude Code가 "컴퓨터 앞에 앉아서 시키는 작업실"이라면 Hermes는 "휴대폰 메신저로 부르는 비서"입니다. 한 번 켜 두면 계속 떠 있어서, 외출 중에도 텔레그램으로 말을 걸 수 있습니다.

어디서내 컴퓨터(윈도우, 맥, 리눅스)나 서버. 꺼지면 일하지 못함
대화 창구텔레그램, 디스코드, 슬랙, 왓츠앱, 시그널, 이메일
AI 모델내가 고름 (클라우드 모델, 내 컴퓨터의 로컬 모델)
라이선스무료 오픈소스(MIT라고 소개됨)

잘하는 일

  • 기억하기. 대화와 일한 내용을 저장해 두고 다음에 이어서 씁니다.
  • 스킬 쌓기. 한 번 해결한 일을 재사용 가능한 방법(스킬)으로 저장합니다.
  • 예약 작업. "월요일 아침 브리핑 보내 줘"처럼 말로 정해 두면 알아서 돕니다.
  • 어느 창구에서든 같은 비서. 텔레그램과 터미널이 같은 기억을 씁니다.

아직 약한 점

  • 설치와 설정이 처음에는 어렵습니다 (모델 연결, 메신저 연결, 허용 목록).
  • 작은 로컬 모델은 복잡한 지시를 놓칠 수 있습니다.
  • 내 컴퓨터에서 도는 비서라 컴퓨터가 꺼지면 멈춥니다.
  • 파일과 명령을 다루는 힘이 있어서 접근 범위를 좁게 제한해야 안전합니다.
휴대폰텔레그램에 "메모: 수요예배 광고 수정"
→

3. Jev

AI 속에 들어가는 "순간 판단" 부품

TypeSafe개발자용

대화하는 AI가 아닙니다. 사람으로 치면 "생각하기 전에 먼저 드는 직감"에 해당하는 작은 모델입니다. 상황을 주고 정해 둔 질문을 하면 선택지와 확률을 바로 돌려줍니다. 회사는 이것을 System One(빠른 직관) 모델이라고 부릅니다.

누가 쓰나프로그램을 만드는 개발자 (일반 사용자가 직접 쓸 일은 드묾)
입력지금 상태 설명 + 미리 정한 질문과 답 선택지
출력선택지별 확률 (프로그램이 이걸로 분기)
출시2026년 9월 중순으로 보도됨
상태기차표 검색 결과: 오전 9시 매진
→
질문다른 시간으로 다시 찾아볼까?
→
Jev의 답예 82% · 아니오 18%
→
프로그램"예"이므로 다른 시간 검색

잘하는 일 (회사 설명 기준)

  • 재시도할지, 어느 도구를 쓸지, 일이 끝났는지, 위험한 행동인지 같은 작은 판단.
  • 큰 AI를 매번 부르는 것보다 빠르고 저렴하다고 소개됩니다.
  • 정해진 선택지 밖의 답은 내지 않아서 프로그램에 끼워 넣기 좋습니다.

알아 둘 점

  • 글을 쓰거나 대화하는 일에는 쓰지 않습니다. 그건 일반 AI(LLM)의 몫입니다.
  • 속도와 비용 수치는 회사 발표가 많고, 정확도가 최고 수준 모델보다 낫다는 독립적인 근거는 아직 부족합니다.
  • 정해진 선택지 안에서도 답이 틀릴 수는 있습니다.
쉽게 말하면 에이전트(Hermes 같은 것)를 직원이라고 하면, Jev는 직원의 머릿속에서 "이건 다시 해 보자", "이건 멈추자"를 순식간에 정해 주는 스위치입니다. 직접 쓰기보다 앞으로 여러 AI 도구 속에서 보이게 될 부품입니다.
4. Aside Browser

웹을 대신 돌아다니는 AI 일꾼

Aside크로미움 기반 브라우저

크롬처럼 생긴 별도의 브라우저 앱입니다. 메일, 관리 화면, 내부 도구 같이 내가 이미 로그인해 둔 사이트에 AI가 들어가서 클릭하고 입력합니다. 사이트마다 연동을 따로 만들 필요가 없다는 점이 핵심입니다.

어디서내 컴퓨터의 데스크톱 앱
AI 모델내 구독이나 키를 연결하는 방식으로 소개됨 (확인 필요)
기억작업 기억을 내 컴퓨터에 편집 가능한 글 파일로 저장
개발 상태출시 초기, 사용 후기가 아직 적음

잘하는 일

  • 여러 사이트를 오가며 여러 단계로 이어지는 일(조사, 정리, 양식 입력, 다운로드).
  • 비밀번호를 AI에게 보여 주지 않고 로그인 화면에 자동 입력하도록 설계했다고 소개됩니다.
  • 결제, 게시, 메시지 보내기 같은 민감한 행동은 사람 승인을 기다린다고 설명합니다.
  • 기억이 읽을 수 있는 글 파일이라, 이상하면 직접 보고 고칠 수 있습니다.

알아 둘 점

  • 성능 순위는 회사가 직접 측정해 발표한 것입니다.
  • 승인 단계가 문서로 확인되지 않았다는 지적이 있어, 처음에는 읽기 위주 일만 맡깁니다.
  • 요금 체계가 자료마다 달라 확정된 가격을 확인해야 합니다.
  • 샌드박스(보호된 공간)에서 도는 경우 내 컴퓨터의 일부 명령이 막힐 수 있습니다. 실제로 홈페이지 수정 작업 때 git 명령이 권한 문제로 막혀 웹 업로드로 대신한 적이 있습니다.
처음 해 볼 일 (읽기 전용)이 사이트의 최근 공지 5개를 제목과 날짜로 표로 정리해 줘. 로그인이나 입력은 하지 마.
메일 정리 (초안만)내 메일함에서 이번 주에 온 요청 메일만 골라 표로 정리해 줘. 답장은 보내지 말고 초안만 만들어 줘.
5. Muse (Meta)

목표만 말하면 알아서 해 주는 앱

Meta개인 에이전트

이름이 같은 다른 서비스(영상 서비스 Muse.ai 등)와 헷갈리기 쉽습니다. 여기서는 메타의 개인 AI 에이전트 Muse를 말합니다. 메타의 AI 모델 Muse Spark 위에서 움직이고, 모델은 2026년 4월에 처음 공개되었습니다.

어디서아이폰·안드로이드 앱, 웹, 왓츠앱 (처음에는 미국에서만)
사용법단계별 지시 대신 목표를 말함
모델메타의 Muse Spark 계열 (공개 모델이 아닌 폐쇄형)
한국 제공확인되지 않음. 제공 지역과 요금은 메타 발표를 확인

잘하는 일 (보도 기준)

  • 자체 브라우저로 양식 작성, 이메일 보내기, 여행 예약, 가격 협상 같은 일상 심부름.
  • 오래 걸리는 일은 앱을 닫아도 계속 진행합니다.
  • 쓸 만한 정보를 기억하고, 먼저 제안도 합니다.

알아 둘 점

  • 메타도 "가끔 실수한다"고 밝혔습니다. 예약과 결제는 반드시 직접 확인하세요.
  • 독립적인 평가는 메타 발표보다 덜 후합니다.
  • 미국 중심 출시라 한국 사용자가 바로 쓰지 못할 수 있습니다.
  • 내 메일과 일정을 맡기는 순간 개인 정보가 메타 서비스로 넘어갑니다.
이런 식으로 말합니다 (목표 중심)다음 주 화요일 서울에서 부산 가는 기차 시간을 비교해서 가장 편한 시간 세 개만 알려 줘. 예약은 하지 마.

새 도구를 만났을 때 지킬 것

  • 처음에는 읽기 전용으로. 파일 삭제, 메일 발송, 결제는 맡기지 않습니다.
  • 회사가 발표한 점수는 참고만. 독립 평가가 나올 때까지 기다리거나 작은 일로 직접 시험합니다.
  • 접근 범위를 좁게. 폴더 하나, 사이트 하나, 계정 하나로 시작합니다.
  • 요금은 직접 확인. 소개 글마다 숫자가 다르고 자주 바뀝니다.
  • 비밀번호, 키, 교인 명단은 AI에게 직접 입력하지 않습니다.
